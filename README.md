# NOOK: LUMINA RUN

A warm-reskin release of NOOK: LUMINA RUN, a browser-based side-scrolling platformer.

## Play

This version is designed for static hosting such as GitHub Pages.

- No Node.js server is required to play.
- Progress is stored locally in the browser with `localStorage`.
- The game supports keyboard and mobile touch controls.
- Progress is tied to the browser/device where it was saved.

## Local testing

Because this is a static game, serve this folder with any static HTTP server, for example:

```bash
npx serve .
```

Then open the local URL in a browser.

## GitHub Pages

The repository root should contain `index.html`, `css/`, and `js/`.

GitHub Pages can publish these static HTML/CSS/JavaScript files directly.

## Controls

- A / Left Arrow — move left
- D / Right Arrow — move right
- Space / W / Up Arrow — jump
- P — pause
- Mobile — use the on-screen controls

## Levels

1. Crystal Caverns
2. Sky Ruins
3. Void Edge
